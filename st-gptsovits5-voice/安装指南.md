# 安装指南（GPT-SoVITS v5 版）

插件只做两件事：**面板 + 调接口**。模型由你自己的 GPT-SoVITS 负责跑。

```
酒馆页面 ──(HTTP)──> GPT-SoVITS api_v2 (:9880)
   扩展               模型 / 权重 / 参考音频都在这里
```

---

## 0. 先确认

| 检查 | 怎么查 |
| --- | --- |
| GPT-SoVITS 能出声音 | 跑过它的 WebUI，两套权重（.ckpt/.pth）+ 一段参考音频能合成 |
| 有 Python | 启 API 用得到（整合包一般自带运行时） |
| 有 git（可选） | 只有用"Install extension"才需要 |

准备好你训练的两组文件（小d / demon 各一组）：

```
xxx.ckpt         ← GPT 权重
xxx.pth          ← SoVITS 权重
ref_xxx.wav      ← 参考音频（10 秒左右）
ref 的原文        ← 参考音频里说的那句话（日文就填日文）
```

---

## 1. 启动 API

在 GPT-SoVITS 根目录：

```bash
python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

看到 `Uvicorn running on http://127.0.0.1:9880` 就行。**别关这个窗口。**

> 只有 WebUI（7860）是不够的——那是网页界面，插件连的是 9880 的 API。

---

## 2. 装扩展

**手动**：把 `st-gptsovits5-voice` 整个文件夹放进

```
SillyTavern\data\default-user\extensions\st-gptsovits5-voice\
```

**或用 git**：把仓库推到 GitHub，酒馆 → 扩展 → Install extension → 粘地址。

刷新酒馆（Ctrl+F5）→ 顶栏出现**耳机**图标。

---

## 3. 处理 CORS（唯一容易卡住的一步）

官方 `api_v2.py` 没挂 CORS，浏览器从酒馆页面（127.0.0.1:8000）直连 9880 会被拦。

**先直接试**：点面板「测试连接」。

| 看到 | 说明 | 下一步 |
| --- | --- | --- |
| `已连接（/control → HTTP 400）` | 你的整合包已加 CORS | 跳过本节 |
| `未连接：Failed to fetch` | 被 CORS 拦了 | 做下面两步 |

1. 双击 `st-gptsovits5-voice\server\start-relay.bat`（起在 9881）
2. 面板地址改成 `http://127.0.0.1:9881`，再点「测试连接」

中继只补 `Access-Control-Allow-Origin` 并原样转发（流式也透传），不改你任何数据。

---

## 4. 建两个音色档案

面板「音色档案」→ 表单：

| 字段 | 小d | demon |
| --- | --- | --- |
| 名称 | `小d · 柔软` | `demon · 小恶魔` |
| GPT 权重 | 小d 的 .ckpt 路径 | demon 的 .ckpt 路径 |
| SoVITS 权重 | 小d 的 .pth 路径 | demon 的 .pth 路径 |
| 参考音频 | `refs/xiaod.wav` | `refs/demon.wav` |
| 参考文本 | 参考音频的日文原文 | 同上 |
| 参考语言 | `ja` | `ja` |

点「保存为新档案」。列表里出现「就绪」即可；显示「缺 GPT 权重」说明路径填错或文件不在服务端能看到的位置。

**路径规则**：相对路径以 GPT-SoVITS 的启动目录为基准；不确定就填绝对路径，
例如 `D:\GPT-SoVITS\GPT_SoVITS\pretrained_models\xiaod.ckpt`。
Windows 路径里的反斜杠直接写，插件会做 URL 编码。

点档案行的 ▶ 可以合成一句固定台词试听（会真的切权重，第一次稍慢）。

---

## 5. 绑到两条声线

1. 酒馆里选中「小鲸鱼娘」
2. 顶栏耳机 → 「当前角色 · 声线」
3. 第一行 `小d · 柔软`：档案选 `小d · 柔软`，语速 `1.00`，文本语言 `自动`
4. 第二行 `demon · 小恶魔`：档案选 `demon · 小恶魔`
5. 圆点选「自动」

然后聊天里点消息上的 🔊 就能听。

**语气怎么来**：GPT-SoVITS 没有情绪参数，语气来自**参考音频本身**。
想让她更软，就用更软的那段做参考；想更"恶魔"，换一段带笑/上扬的参考。

## 6. 常见问题

**点朗读没反应，控制台 `Failed to fetch`**
→ CORS。走第 3 节的中继。

**`/tts` 返回 400，说 text_lang is not supported**
→ 你的模型版本不支持该语言。面板「文本语言」手动选 `zh`（中文文本）或 `ja`。

**合成出来不像 / 含糊**
→ 九成是参考音频或参考文本的问题：参考要干净（无 BGM）、10 秒左右、**参考文本必须一字不差**。
参考文本空着也能合成，但质量明显下降。

**切换声线要卡几秒**
→ 正常。`/set_gpt_weights` 会真的加载权重。插件缓存了"已加载的权重对"，同一声线连续使用不会重复切。

**声音和文本语言对不上（中文念成日式）**
→ 参考音频是日文时，中文会带一点口音，这是跨语种的固有现象。把「文本语言」显式设成 `zh` 通常最稳。

**sample_steps 填多少**
→ v5 系列常用 32；留空用服务端默认。填了没效果说明你的模型不是 v3/v5 系列。

## 7. 更新 / 卸载

| 操作 | 做法 |
| --- | --- |
| 更新扩展 | 覆盖文件夹；git 装的话扩展面板 Check for updates |
| 卸载 | 删文件夹 + 取消勾选 |
| 绑定数据在哪 | 酒馆 `settings.json` 里的 `gptsovits5_voice` 键 |
| 声线接口在哪 | 角色卡 `data.extensions.gptsovits5`，跟卡走 |
